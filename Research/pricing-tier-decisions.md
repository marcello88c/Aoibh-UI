# Pricing Structure — Quarterly Tier & One-Off Pack

Status: **Quarterly billing — parked, not built. One-off pack — named
"Trial Project," built and live on the pricing section.**

## Quarterly tier: parked

**Decision: hold off.** Not because the idea is bad — because it directly
contradicts something already live and doing real trust-building work.

The FAQ states plainly: *"subscriptions run month to month with no
long-term lock-in... cancel ahead of your next billing date."* Asking a
client to prepay three months upfront, before there's any real retention
data proving clients stay happy past month one, is a bigger reputational
risk than the cash-flow benefit is worth this early. If a quarterly client
has a bad first project, that's a refund/trust problem stacked on top of a
churn problem — for a studio with zero track record to fall back on yet.

**If the actual goal resurfaces later** (better cash flow, reduced churn
risk), the lower-risk version isn't a separate quarterly *commitment*
tier — it's a **quarterly billing discount on the existing monthly tiers**
("save 10% paying quarterly," a toggle, not a different plan). Same
cancellation flexibility as today, just prepaid in a bigger chunk. Worth
revisiting once there's real retention data to justify it — same class of
decision as the parked competitor-comparison chart and the parked real
testimonials: not wrong, just premature pre-launch.

## One-off pack: "Trial Project" — built and live

Revisits the one-off pricing menu that was explicitly skipped early on,
with its own framing already on record: *"ideal for bringing new customers
into the ecosystem before encouraging them to move to a subscription."*
Now that the subscription tiers are fully scoped, worth building.

### The spec

| | |
|---|---|
| **Name** | Trial Project |
| **Price** | €695 |
| **Scope** | One project — same definition used everywhere else on the pricing page (a single deliverable: one logo, one set of brand guidelines, one landing page, etc. — not a bundle) |
| **Revisions** | 1 round (not the subscriptions' 2 — see reasoning below) |
| **Eligibility** | New clients only |

### Why €695, not literal break-even

Designer payout (COGS) is ~€500/project — the same baseline used to set
every subscription tier. Break-even at exactly that number was
deliberately rejected: zero margin means any hiccup (an extra revision, a
slow-paying client) turns the project into a real loss, the same trap the
subscription tiers were built to avoid.

€695 gives roughly **28% margin** — thin, but real. Margin options
considered:

| Margin target | Price |
|---|---|
| 20% | €625 |
| 25% | €670 |
| **28% (chosen)** | **€695** |
| 30% | €715 |
| 35% | €770 |

€695 was chosen specifically because it clears a real psychological
threshold — meaningfully under €700, and clearly lower-commitment than the
cheapest subscription (Starter, €1,250/month), which is the whole point of
the offer as an acquisition tool. Still a clean, sensible number rather
than one that visibly looks reverse-engineered from a margin target.

### Why 1 revision round, not 2

Not a punishment for one-off buyers — margin discipline. A thin-margin
offer is exactly where an extra revision round costs proportionally the
most. Same "state the limit clearly, protect it consistently" approach
already used for the subscription tiers' revision caps and the "one
project" definition — the pattern that's protected margin everywhere else
on this pricing page should protect this offer too, not get relaxed for it.

### Why new-clients-only

Without that gate, this stops being an acquisition tool and starts being a
loophole: an existing subscriber could just keep buying discounted one-offs
indefinitely instead of subscribing, undermining the subscription funnel
this whole pricing structure is built around.

### Naming collision — resolved

The original name floated for this, "Starter Studio," sat close enough to
the existing **Starter** subscription tier that confusion between the two
was likely. Resolved by naming it **Trial Project** instead — no overlap
with any subscription tier name, and it states plainly what the offer
actually is.

No recommendation locked in yet — genuinely worth a second look before
building it into the actual pricing section.
